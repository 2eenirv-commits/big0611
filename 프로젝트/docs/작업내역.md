## 4. 시스템 아키텍처

```
[사용자 브라우저]
    │  HTML · CSS · JS · Bootstrap 5 · Flexbox
    ▼
[Spring Boot 3.5 + Thymeleaf + Tomcat 10.1]
    │  Spring Web · Security · JDBC Template
    ▼
[MySQL 8 / TiDB Cloud]
    ▲
[RPA + AI (Python)]
    NumPy · Pandas · Matplotlib · Seaborn · Plotly · Scikit-learn
```

**데이터 흐름**

1. 사용자 → Controller → Service → JdbcTemplate → DB
2. Python RPA → 외부 매물 사이트 크롤링 → DB/분석
3. 분석 결과 → Plotly 차트 또는 웹 대시보드 연동
